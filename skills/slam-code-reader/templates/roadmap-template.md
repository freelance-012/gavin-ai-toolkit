### 3.2 分阶段指引

#### Stage 1: 入门 — 建立全局认知（预计 2-3 小时）

**目标**: 能够画出系统架构图，知道每个模块干什么

**读什么**:
- [ ] `00_资料清单.md` → 了解有哪些论文可参考
- [ ] `01_拓扑结构分析.md` → 了解目录结构和模块职责
- [ ] `main()` 函数 → 了解系统启动流程
- [ ] 快速浏览 `02_数据流追踪.md` → 了解数据怎么流转

**关注重点**:
- 有几个线程？各自干什么？
- 传感器数据从哪进、从哪出？
- 核心模块是哪些？

**预期收获**: 能给别人讲清楚这套代码的整体架构

---

#### Stage 2: 进阶 — 攻克核心算法（预计 8-14 小时）

**目标**: 理解核心数学原理，能看懂公式对应的代码

**读什么**: 所有 P0 模块的精读文档 (`04/*.md`)

**建议顺序**: 按上表 Step 4 → 5 → 6 → 7

**阅读方法**:
1. 先看精读文档的 Section 1（定位）和 Section 2（数据结构）
2. 打开论文对应章节，理解公式
3. 对照 Section 3 的公式↔代码映射，逐行看代码
4. 如果某处不理解，回到论文重读相关推导
5. 在代码中加注释，写自己的理解

**关注重点**:
- 预积分：离散化方式、雅可比如何更新、协方差如何传播
- 初始化：纯视觉 SfM 怎么做、IMU 如何与 SfM 对齐
- 优化：状态向量是什么、残差有几种、如何构建
- 边缘化：边缘谁、先验信息怎么构造

**预期收获**: 能解释清楚每行关键代码在算什么

---

#### Stage 3: 精通 — 工程细节与调参（预计 1-2 小时）

**目标**: 能独立调参、debug 问题、评估性能

**读什么**:
- `05_参数清单.md` → 了解所有可调参数
- P1/P2 模块源码（选择性阅读）
- 配置文件的实际内容

**动手实践**:
- [ ] 用推荐数据集跑通 baseline
- [ ] 记录 ATE/RPE 指标
- [ ] 改一个参数看效果变化
- [ ] 在困难场景下测试鲁棒性

**预期收获**: 能独立部署和调试这套系统

## 六、快速验证指南

### 6.1 推荐数据集

| 项目类型 | 推荐数据集 | 获取方式 | 评估指标 | 典型 ATE 参考 |
|---------|-----------|---------|---------|---------------|
| 单目 VIO | EuRoC MAV Dataset | [官网](https://projects.asl.ethz.ch/datasets/doku.php?id=kmavvisualinertialsensorssuite) 免费 | ATE RMSE (m) | 0.1 ~ 0.5 (difficult 更高) |
| 双目 VIO | EuRoC / KITTI Odometry | 免费 | ATE / RPE | 视具体序列 |
| RGB-D SLAM | TUM RGB-D Dataset | [官网](https://vision.in.tum.de/data/datasets/rgbd-dataset) 免费 | ATE RMSE | cm 级 |
| 激光 SLAM | KITTI Odometry | [官网](www.cvlibs.net/datasets/kitti/eval_odometry.php) | Trans./Rot. Error (%) | 视具体方法 |

### 6.2 验证步骤

```
Step 1: 编译通过 ✅
  $ mkdir build && cd build && cmake .. && make -j4
  预期: 无错误，生成可执行文件

Step 2: 跑通一个简单序列 ✅
  $ ./run {config} {dataset_path}
  预期: 正常输出轨迹，无 crash

Step 3: 记录 baseline 指标 📊
  使用默认配置跑推荐的 "easy" 序列
  记录: ATE_RMSE, 平均跟踪时间, 处理帧率

Step 4: 改参实验 🔬
  改动: window_size: 10 → 15
  对比: ATE 变化? 跟踪稳定性? 计算耗时?

Step 5: 困难场景测试 ⚡
  选择 dynamic / difficult 序列
  观察: 是否频繁 lost? 重启次数? 漂移程度?
```

### 6.3 推荐 Debug 断点

| 目的 | 断点位置 | 条件 | 观察内容 |
|------|---------|------|---------|
| 确认 IMU 到达 | `estimator.cpp:{line}` | 回调触发 | 时间戳间隔是否 ~10ms |
| 确认预积分正常 | `integration_base.cpp:{line}` | 每次 push_back | delta_p/v/q 是否合理递增 |
| 确认优化收敛 | `estimator.cpp:{line}` | solve 后 | cost 是否下降、迭代几次 |
| 检测跟踪丢失 | `tracker.cpp:{line}` | status 变更 | lost count 和恢复情况 |
