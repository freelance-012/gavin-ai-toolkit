### 7.2 调参指南

#### 场景 A: 精度不够

**症状**: 轨迹漂移明显、ATE/RPE 过大
**排查顺序**:
1. 检查 IMU 噪声参数是否与实际传感器匹配
2. 尝试增大窗口大小 (`window_size`)
3. 检查特征数量是否足够
4. 调整视觉/IMU 残差权重比

#### 场景 B: 容易跟踪丢失

**症状**: 频繁出现 tracking lost、系统重启
**排查顺序**:
1. 降低跟踪阈值
2. 增大 RANSAC 阈值容忍度
3. 检查图像质量（运动模糊、曝光）
4. 调整特征提取参数（增加特征数）

#### 场景 C: 计算太慢，达不到实时

**症状**: 处理一帧耗时 > 帧间隔
**优化方向**:
1. 减小滑动窗口大小
2. 降低图像分辨率 (`image_scale`)
3. 减少 Ceres 最大迭代次数
4. 启用 GPU 加速（如果支持）

#### 场景 D: 更换了新的传感器

**操作清单**:
1. [ ] 重新标定相机内参
2. [ ] 重新标定 IMU 噪声参数 (Allan 方差分析)
3. [ ] 重新标定 IMU-Camera 外参
4. [ ] 更新 `time_offset`
5. [ ] 用新配置跑 baseline 序列验证
