# SLAM 代码审查检查清单

> 用于审查 SLAM/VIO 相关代码时的检查项。
> 可被 slam-reviewer Agent 引用。

---

## 1. 数值稳定性

- [ ] 四元数归一化是否在每次更新后执行？
- [ ] 矩阵求逆前是否检查奇异性（条件数）？
- [ ] 是否处理了退化情况（纯旋转、共线点、特征不足）？
- [ ] 浮点比较是否使用 epsilon 而非直接 `==`？
- [ ] 是否有数值溢出/下溢的保护？

## 2. 坐标系一致性

- [ ] IMU 坐标系定义是否明确（FRD / FLU / RD）？
- [ ] 相机坐标系定义是否明确（前-右-下 / 前-左-上）？
- [ ] 世界坐标系初始化方式是否合理？
- [ ] 外参 T_bc 的定义方向是否正确？
- [ ] 所有坐标系变换是否有注释说明？

## 3. 时间同步

- [ ] 图像和 IMU 时间戳是否对齐？
- [ ] 是否有 time_offset 参数？如何标定？
- [ ] 时间戳单位是否一致（s vs ms vs ns）？
- [ ] 是否处理了时间戳回退/跳变？

## 4. 线程安全

- [ ] 共享数据是否有 mutex 保护？
- [ ] 是否存在死锁风险？
- [ ] 队列操作是否原子化？
- [ ] 发布/订阅的数据是否有拷贝还是引用？

## 5. 内存管理

- [ ] 是否有内存泄漏？（new/delete 配对、智能指针使用）
- [ ] 滑动窗口中的帧释放是否及时？
- [ ] 特征点和地图点的生命周期管理是否正确？
- [ ] 大对象是否避免不必要的拷贝？

## 6. 算法正确性

### 预积分
- [ ] 雅可比矩阵的推导是否正确？
- [ ] 协方差传播是否考虑了 bias 变化？
- [ ] 中点积分/ RK 的实现是否符合论文？

### 优化
- [ ] 信息矩阵是否对称正定？
- [ ] 参数化是否有奇异点（如四元数双覆盖）？
- [ ] LocalParameterization 是否正确设置？
- [ ] Loss Function 是否合理选择？

### 边缘化
- [ ] Schur 补的实现是否正确？
- [ ] FEJ 是否正确保存首次估计？
- [ ] 先验信息是否正确构造和传递？

## 7. 性能

- [ ] 热循环中是否有不必要的内存分配？
- [ ] 矩阵运算是否充分利用 Eigen 的 SIMD？
- [ ] 是否有不必要的拷贝或类型转换？
- [ ] 关键路径的时间复杂度是否合理？

## 8. 可维护性

- [ ] 关键算法是否有注释引用对应论文公式？
- [ ] 魔术数字是否有命名常量？
- [ ] 函数长度是否合理（<100 行）？
- [ ] 错误处理是否完善？
- [ ] 日志级别是否合理（DEBUG/INFO/WARN/ERROR）？
