# Phase 0: 症状分类

## 目标

通过用户描述或自动检测，确定 SLAM 系统的故障类型，为后续诊断提供方向。

## 触发词

- "诊断问题"
- "分类症状"

## 依赖

无（可作为第一个执行的 Phase）

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| symptom | string | ⬜ | 用户描述的症状（可选） |

## 输出产物

不生成文件，但确定故障类型供后续 Phase 使用。

## 执行步骤

### Step 1: 接收症状描述

如果用户已提供症状描述，直接分析。否则，通过问答获取：

```
请描述你遇到的问题（选择最接近的）：

1. **轨迹漂移** - 轨迹随时间逐渐偏离真值，误差单调增长
2. **轨迹发散** - 轨迹快速偏离，误差急剧增大，系统完全失效
3. **跟踪丢失** - 特征点跟踪突然中断，无法继续估计位姿
4. **初始化失败** - 系统无法完成初始化，无法开始正常估计
5. **回环检测失败** - 无法检测到已访问过的地方，或检测到错误回环
6. **其他问题** - 请描述具体现象
```

### Step 2: 症状分类

根据用户描述，匹配到预定义的故障类型：

#### 2.1 轨迹漂移（Drift）

**关键词匹配**：
- "漂移"、"逐渐偏离"、"误差增长"、"drift"

**特征**：
- 误差随时间单调增长
- 系统仍能运行，但精度逐渐下降
- 通常在运行一段时间后出现

#### 2.2 轨迹发散（Divergence）

**关键词匹配**：
- "发散"、"完全偏离"、"误差爆炸"、"diverge"

**特征**：
- 误差急剧增大（秒级别）
- 系统完全失效
- 通常在初始化后不久或特定时刻发生

#### 2.3 跟踪丢失（Tracking Loss）

**关键词匹配**：
- "跟踪丢失"、"特征丢失"、"tracking lost"

**特征**：
- 特征点数量突然下降
- 系统无法继续估计位姿
- 可能伴随"重定位"尝试

#### 2.4 初始化失败（Initialization Failure）

**关键词匹配**：
- "初始化失败"、"无法初始化"、"init fail"

**特征**：
- 系统启动后无法进入正常状态
- 可能反复尝试初始化
- 通常需要特定运动模式

#### 2.5 回环检测失败（Loop Closure Failure）

**关键词匹配**：
- "回环失败"、"无法闭合"、"loop closure fail"

**特征**：
- 回到已访问的地方但无法检测
- 或检测到错误的回环
- 地图一致性差

### Step 3: 确认故障类型

向用户确认分类结果：

```
根据描述，我判断这是 **{故障类型}** 问题。

特征匹配:
- {特征1}
- {特征2}
- {特征3}

是否正确？(Y/n)
如果不正确，请补充更多信息。
```

### Step 4: 确定诊断方向

根据故障类型，确定后续需要收集的信息：

| 故障类型 | 重点关注 |
|---------|---------|
| 轨迹漂移 | 评估结果的时序分析、IMU 参数、外参、尺度 |
| 轨迹发散 | 初始化阶段日志、外参、噪声参数、坐标系 |
| 跟踪丢失 | 特征数量变化、运动速度、场景纹理 |
| 初始化失败 | 初始化阶段日志、运动激励、特征分布 |
| 回环检测失败 | 回环候选数量、描述子阈值、几何验证 |

## 注意事项

1. **症状可能重叠**：用户描述可能包含多种症状，选择最主导的
2. **允许修正**：如果用户否定分类，重新询问或让用户直接说明
3. **记录不确定**：如果无法确定，标注"待确认"，在 Phase 1 中进一步收集信息
4. **多故障并存**：如果系统有多个问题，记录所有症状，按优先级诊断
