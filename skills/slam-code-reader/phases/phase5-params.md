# Phase 5: 参数清单提取

## 目标

扫描配置文件和代码中的参数读取逻辑，提取全部可调参数，生成速查表。为后续调参、部署、调试提供参考。

## 触发词

- "提取参数"
- "参数清单"
- "有哪些可调参数"

## 依赖

**必需**: `01_拓扑结构分析.md`（需要了解项目结构和配置文件位置）

**检查逻辑**：
```
如果 01_拓扑结构分析.md 不存在:
    → 停止，提示先执行 Phase 1
```

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| repo_path | string | ✅ | 仓库根目录绝对路径 |

## 输出产物

```
{仓库名}-code-analysis/
└── 05_参数清单.md
```

## 执行步骤

### Step 1: 扫描所有配置文件

使用 Glob 搜索：

```
*.yaml, *.yml, *.json, *.cfg, *.conf
*.launch (ROS)
*.config, *.ini
```

记录每个配置文件的路径和用途（从文件名或注释推断）。

### Step 2: 从配置文件提取参数

对每个配置文件：
- 提取所有键值对
- 记录默认值
- 如果有注释，提取注释内容作为含义说明

### Step 3: 搜索代码中的参数读取位置

搜索以下模式：

| 模式 | 含义 |
|------|------|
| `getParam`, `param<T>()` | ROS 参数服务器读取 |
| `node_handle.param` | ROS NodeHandle 参数 |
| `cv::FileStorage` | OpenCV 文件存储读取 |
| `YAML::LoadFile` | YAML-CPP 库读取 |
| `readConfig`, `loadParam` | 自定义参数加载函数 |
| `#define`, `constexpr` | 编译期常量/硬编码参数 |

对每个匹配项，记录：
- 参数名
- 读取位置（文件:行号）
- 默认值
- 使用该参数的代码位置（如果容易追踪）

### Step 4: 参数分类标注

将每个参数归入以下类别之一：

#### 4.1 精度相关参数
影响最终估计精度：
- 优化器迭代次数 (`max_iterations`)
- 收敛阈值 (`convergence_threshold`)
- 特征数量/质量阈值 (`max_features`, `min_parallax`)
- 残差权重 (`weight_visual`, `weight_imu`)

#### 4.2 鲁棒性相关参数
影响系统在困难场景下的稳定性：
- 跟踪丢失判断阈值 (`tracking_threshold`, `max_track_loss`)
- RANSAC 阈值 (`ransac_threshold`)
- 异常值剔除策略 (`loss_function`, `kernel_type`)
- 外点拒绝比例 (`outlier_ratio`)

#### 4.3 性能相关参数
影响运行效率：
- 线程数 (`num_threads`)
- 滑动窗口大小 (`window_size`, `slide_window_size`)
- 图像降采样率 (`image_scale`, `col, row`)
- 最大求解时间 (`max_solver_time`)

#### 4.4 硬件相关参数
与具体传感器/平台绑定：
- 相机内参 (`fx, fy, cx, cy, k1, k2, p1, p2`)
- IMU 噪声参数 (`acc_n, gyr_n, acc_w, gyr_w`)
- IMU-相机外参 (`p_ic, q_ic`, 即 T_bc)
- 时间偏移 (`time_offset`)

### Step 5: 推断参数含义和推荐范围

对于没有注释的参数：
- 根据参数名和上下文推断物理含义
- 根据常见取值范围给出推荐调参范围
- 标注推断置信度（高/中/低）

**常用参数的典型范围参考**：

| 参数 | 典型范围 | 说明 |
|------|---------|------|
| acc_n (加速度计噪声) | 0.01 ~ 0.5 m/s²/√Hz | 取决于 IMU 型号 |
| gyr_n (陀螺仪噪声) | 0.0001 ~ 0.05 rad/s/√Hz | 同上 |
| acc_w (加速度计随机游走) | 1e-5 ~ 1e-3 | bias 不稳定程度 |
| gyr_w (陀螺仪随机游走) | 1e-6 ~ 1e-4 | 同上 |
| window_size (窗口大小) | 8 ~ 20 帧 | 越大精度越高但越慢 |
| max_iter (优化迭代次数) | 4 ~ 20 次 | 通常 8-10 次足够收敛 |
| ransac_threshold | 1.0 ~ 3.0 pixel | 像素单位 |

### Step 6: 生成报告

套用 `templates/param-list-template.md` 格式：

```markdown
# 05_参数清单

> 仓库: {仓库名} | 生成日期: {日期}

## 1. 配置文件总览
   | 文件路径 | 格式 | 用途 |

## 2. 精度相关参数
   | 参数名 | 默认值 | 定义位置 | 所属模块 | 含义 | 推荐范围 | 敏感度 |

## 3. 鲁棒性相关参数
   (同上格式)

## 4. 性能相关参数
   (同上格式)

## 5. 硬件相关参数
   (同上格式)

## 6. 其他参数
   (未归入上述类别的)

## 7. 参数影响分析
   (文字段落：关键参数之间的相互影响、调参建议)

## 8. 快速调参指南
   - 场景1: 精度不够 → 调哪些参数
   - 场景2: 容易跟踪丢失 → 调哪些参数
   - 场景3: 计算太慢 → 调哪些参数
   - 场景4: 换了新传感器 → 改哪些参数
```

## 注意事项

1. **区分"可调"和"不可调"**：有些参数是算法常数（如 PI），不需要列入
2. **标注来源可靠性**：有注释的参数标注 ✅，推断的参数标注 🔍
3. **注意参数间的耦合**：某些参数一起改才有效果（如 IMU 噪声参数通常需要成组调整）
4. **Phase 4 的精读文档中也包含局部参数**：本 Phase 是全局汇总，两者互补
