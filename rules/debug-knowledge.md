# SLAM 故障诊断知识库

本文件包含 SLAM 系统的通用故障模式、根因分析和诊断决策树。

---

## 1. 故障类型分类

### 1.1 轨迹漂移（Drift）

**定义**: 轨迹随时间逐渐偏离真值，误差单调增长

**特征**:
- 误差随时间单调增长
- 系统仍能运行，但精度逐渐下降
- 通常在运行一段时间后出现（>10s）

**典型表现**:
- ATE RMSE 随时间增大
- 误差曲线呈上升趋势
- 系统不会完全失效

### 1.2 轨迹发散（Divergence）

**定义**: 轨迹快速偏离，误差急剧增大，系统完全失效

**特征**:
- 误差急剧增大（秒级别）
- 系统完全失效
- 通常在初始化后不久或特定时刻发生

**典型表现**:
- 轨迹突然跳变
- 误差 > 1m 或更大
- 系统无法继续估计

### 1.3 跟踪丢失（Tracking Loss）

**定义**: 特征点跟踪突然中断，系统无法继续估计位姿

**特征**:
- 特征点数量突然下降
- 系统无法继续估计位姿
- 可能伴随"重定位"尝试

**典型表现**:
- 日志显示"tracking lost"
- 特征数量 < 阈值
- 位姿估计停止

### 1.4 初始化失败（Initialization Failure）

**定义**: 系统无法完成初始化，无法开始正常估计

**特征**:
- 系统启动后无法进入正常状态
- 可能反复尝试初始化
- 通常需要特定运动模式

**典型表现**:
- 日志显示"initialization failed"
- 初始化尝试次数 > 阈值
- 系统停留在初始化阶段

### 1.5 回环检测失败（Loop Closure Failure）

**定义**: 无法检测到已经访问过的地方，或检测到错误的回环

**特征**:
- 回到已访问的地方但无法检测
- 或检测到错误的回环
- 地图一致性差

**典型表现**:
- 回环候选数量 = 0
- 或回环后地图错乱
- 位姿图不闭合

## 2. 通用根因分析

### 2.1 传感器相关

#### 外参错误

**常见错误**:
1. **平移单位错误**: mm vs m（1000倍误差）
2. **旋转错误**: 四元数顺序错误（xyzw vs wxyz）
3. **坐标系不一致**: FLU vs ENU vs NED
4. **外参未标定**: 使用默认值或错误值

**诊断方法**:
- 检查配置文件中的外参
- 确认单位是否正确
- 验证坐标系定义
- 对比 CAD 数据或标定结果

**修复方法**:
- 修正单位（mm → m）
- 修正四元数顺序
- 重新标定外参
- 使用正确的手系定义

#### 时间同步问题

**常见错误**:
1. **时间戳偏移**: IMU 和相机时间戳不对齐（>10ms）
2. **时间戳单位**: 秒 vs 毫秒 vs 纳秒
3. **时间戳延迟**: 数据传输延迟未补偿

**诊断方法**:
- 检查日志中的时间戳
- 计算 IMU 和相机的时间差
- 检查时间戳单位

**修复方法**:
- 添加时间偏移补偿
- 统一时间戳单位
- 使用硬件同步

### 2.2 IMU 相关

#### IMU 噪声参数

**常见错误**:
1. **噪声过大**: >1.0（系统过于依赖视觉）
2. **噪声过小**: <1e-6（数值不稳定）
3. **单位错误**: deg vs rad

**诊断方法**:
- 检查配置文件中的噪声参数
- 对比 IMU 数据表
- 观察优化过程中的残差

**修复方法**:
- 使用 IMU 数据表的推荐值
- 调整噪声参数（典型范围: gyro [1e-4, 1e-2], accel [1e-3, 1e-1]）

#### IMU 零偏

**常见错误**:
1. **零偏未标定**: 使用默认值 0
2. **零偏估计不准**: 在线估计时收敛不好
3. **零偏漂移**: 温度变化导致零偏变化

**诊断方法**:
- 检查零偏估计值
- 观察零偏随时间的变化
- 检查静止时的 IMU 数据

**修复方法**:
- 进行静态标定
- 调整零偏估计参数
- 添加温度补偿

### 2.3 视觉相关

#### 特征提取

**常见错误**:
1. **特征数量不足**: <50（跟踪不稳定）
2. **特征分布不均**: 集中在边缘或平面
3. **特征质量差**: 响应值低，容易丢失

**诊断方法**:
- 检查日志中的特征数量
- 可视化特征分布
- 检查特征响应值

**修复方法**:
- 增加 MAX_FEATURES 参数
- 调整特征提取阈值
- 使用不同的特征提取方法

#### 特征匹配

**常见错误**:
1. **内点比例低**: <30%（匹配质量差）
2. **误匹配多**: 外点比例过高
3. **匹配策略不当**: 搜索范围太大/太小

**诊断方法**:
- 检查日志中的内点比例
- 可视化匹配结果
- 检查匹配距离阈值

**修复方法**:
- 调整匹配阈值
- 使用更好的匹配策略（如交叉检验）
- 添加几何验证

### 2.4 优化相关

#### 优化收敛

**常见错误**:
1. **优化发散**: 残差增大
2. **收敛到局部最优**: 残差未最小化
3. **迭代次数不足**: 提前终止

**诊断方法**:
- 检查优化日志
- 观察残差变化
- 检查迭代次数

**修复方法**:
- 调整优化参数（步长、迭代次数）
- 改进初始值
- 添加正则化

#### 边缘化

**常见错误**:
1. **边缘化策略错误**: 边缘化了错误的状态
2. **数值不稳定**: Schur 补计算错误
3. **信息丢失**: 边缘化后信息矩阵不正定

**诊断方法**:
- 检查边缘化代码逻辑
- 观察信息矩阵的条件数
- 检查边缘化后的残差

**修复方法**:
- 调整边缘化策略
- 添加数值稳定性检查
- 使用更鲁棒的边缘化方法

## 3. 诊断决策树

### 3.1 轨迹漂移决策树

```
轨迹漂移
├─ 1. 尺度问题（单目系统）
│  ├─ 检查尺度是否收敛
│  └─ 检查尺度变化趋势
│
├─ 2. IMU 参数
│  ├─ 检查零偏是否估计
│  ├─ 检查零偏值是否合理
│  └─ 检查噪声参数是否合理
│
├─ 3. 外参
│  ├─ 检查外参旋转是否准确
│  └─ 检查外参平移是否准确
│
├─ 4. 特征跟踪
│  ├─ 检查特征数量是否充足
│  ├─ 检查内点比例是否合理
│  └─ 检查跟踪是否稳定
│
└─ 5. 优化
   ├─ 检查优化是否收敛
   └─ 检查残差是否合理
```

### 3.2 轨迹发散决策树

```
轨迹发散
├─ 1. 初始化
│  ├─ 检查初始化是否成功
│  └─ 检查初始化质量
│
├─ 2. 外参（最高优先级）
│  ├─ 检查平移单位是否正确
│  ├─ 检查旋转是否正确
│  └─ 检查坐标系是否一致
│
├─ 3. 时间同步
│  ├─ 检查时间戳是否对齐
│  └─ 检查时间戳单位是否一致
│
├─ 4. 噪声参数
│  ├─ 检查噪声是否过大
│  ├─ 检查噪声是否过小
│  └─ 检查噪声参数单位是否正确
│
└─ 5. 数据质量
   ├─ 检查 IMU 数据是否正常
   └─ 检查图像是否正常
```

### 3.3 跟踪丢失决策树

```
跟踪丢失
├─ 1. 运动
│  ├─ 检查运动是否过快
│  └─ 检查是否有剧烈旋转
│
├─ 2. 特征
│  ├─ 检查特征数量是否充足
│  ├─ 检查特征分布是否均匀
│  └─ 检查特征质量如何
│
├─ 3. 匹配
│  ├─ 检查内点比例是否合理
│  └─ 检查是否有大量误匹配
│
├─ 4. 场景
│  ├─ 检查是否纹理不足
│  ├─ 检查是否有大量动态物体
│  └─ 检查是否有遮挡
│
└─ 5. 相机
   ├─ 检查曝光是否正常
   └─ 检查是否有运动模糊
```

## 4. 常见问题速查表

| 症状 | 最可能根因 | 快速检查 | 修复方法 |
|------|-----------|---------|---------|
| 轨迹发散（立即） | 外参单位错误 | 检查平移单位 | mm → m |
| 轨迹发散（延迟） | 噪声参数错误 | 检查噪声值 | 调整到合理范围 |
| 轨迹漂移（单目） | 尺度模糊 | 检查尺度收敛 | 添加尺度约束 |
| 轨迹漂移（VIO） | IMU 零偏 | 检查零偏估计 | 重新标定 |
| 跟踪丢失（快速） | 运动过快 | 检查运动速度 | 降低运动速度 |
| 跟踪丢失（纹理） | 特征不足 | 检查特征数量 | 增加 MAX_FEATURES |
| 初始化失败 | 运动激励不足 | 检查运动模式 | 添加激励运动 |
| 回环失败 | 描述子阈值 | 检查阈值设置 | 调整阈值 |

## 5. 调试技巧

### 5.1 添加调试日志

在关键位置添加日志，帮助诊断问题：

```cpp
// 示例：在优化前后添加日志
LOG(INFO) << "Before optimization: cost = " << initial_cost;
optimizer.solve();
LOG(INFO) << "After optimization: cost = " << final_cost 
          << ", iterations = " << iterations;
```

### 5.2 可视化检查

使用可视化工具检查：
- 特征点分布
- 匹配结果
- 轨迹对比
- 协方差椭圆

### 5.3 参数扫描

如果不确定参数值，可以进行参数扫描：

```bash
for noise in 0.001 0.01 0.1; do
    ./run_slam --gyro_noise $noise
    ./evaluate
done
```
